A short note

Privacy

This is a static website. It does not create accounts, and it does not take payments.

What this site stores

Your allocation draft can be saved in this browser only (local storage), so you can come back to the same preference code. Clearing site data deletes it. Nothing is posted to a backend from these pages.

The preference code is also written into the page URL after the #. That fragment stays in the browser; it is not sent to GitHub Pages as part of the request. Still, avoid sharing a screenshot of the full page if you do not want others to see your draft code.

What this site does not collect

  • No names of the child, and no donor account is created here.
  • No analytics, advertising, or social pixels are included in v1.
  • No Stripe, PayPal, cards, or other payment processors.
  • No third-party webfonts — typefaces come from your device.

What a bank would see — later

Until the Juniorkonto is open, please do not transfer. When a SEPA transfer is possible, your bank and the custodians will see the usual payment fields. That is ordinary banking, not something this website processes. This site never publishes a made-up IBAN.

Hosting

Pages are hosted on GitHub Pages. GitHub will see ordinary web-server logs (IP address, user agent) as any static host might. See GitHub’s own privacy documentation for that layer.

Not advice, not a product sale

Nothing on this site is investment advice or an offer to buy or sell securities. Donors do not buy a sleeve here. Parents, as custodians, decide if, when, and how to invest later.
